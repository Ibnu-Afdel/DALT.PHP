# FS02.4 lab — Functions, generics and reusable types

This course-owned lab is copied to `.dalt/workspace/fs02-4-typescript-functions-lab`. It is isolated from earlier labs and from the future Issue Tracker.

    mkdir -p .dalt/workspace
    cp -R .dalt/course/fullstack/typescript-functions-lab/starter .dalt/workspace/fs02-4-typescript-functions-lab
    cd .dalt/workspace/fs02-4-typescript-functions-lab
    npm ci

TypeScript 5.9.3, strict checking, and `exactOptionalPropertyTypes` are pinned in the starter. `npm run stage:return-contract`, `stage:callbacks`, `stage:constraint`, and `stage:utility-model-change` deliberately report compiler errors: read the diagnostic, then repair a copy or make the stated change. `npm run typecheck` and `npm run run` are the clean final checks. Delete only `.dalt/workspace/fs02-4-typescript-functions-lab` and copy again to reset. Generated `dist/` stays inside ignored workspace state.
